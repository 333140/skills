# Contract Review Skill 

**版本** v2.0.0 丨**作者**：浮生模样（微信公众号 fsmy-2020）| **许可**：MIT

合同审查技能 — 智能合同审查工具，通过批注方式标注问题而不修改原文内容。

## 特性

### 五层审核模型

| 层级 | 名称 | 检查项数 | 说明 |
|------|------|---------|------|
| Layer 0 | 合法性前置审查 | 6 项 | 检查合同效力瑕疵（新增） |
| Layer 1 | 基础审核 | 4 项 | 文本质量、格式一致性 |
| Layer 2 | 商业条款 | 8 项 | 标的、价格、交付、知识产权等 |
| Layer 3 | 法律条款 | 8 项 | 管辖、违约、争议解决等 |
| 专项 | 差异化检查 | 按类型加载 | 涉外/电子合同等专项 |

### v2.0.0 新增特性

- **Layer 0 合法性前置审查** — 6 项必查，命中均为 🔴 高风险
- **合同类型自动识别** — 8 种合同类型 + 差异化检查项自动加载
- **强制法律免责声明** — 所有输出文件必须包含
- **检查项优先级体系** — P0（必须批注）/ P1（有问题时批注）/ P2（建议性提示）
- **四段式审核意见** — 总体评估 → 重大风险摘要 → 谈判优先级 → 签署前置条件
- **涉外合同专项检查** — F.1-F.6 六项专项
- **电子合同合规检查** — E.1-E.4 四项专项
- **大型文档分段处理** — 50 页以上自动分段审核 + 跨段一致性验证
- **版本管理与审计轨迹** — UUID + SHA-256 + 审核日期

### 合同类型识别

| 类型 | 识别关键词 | 附加检查项 |
|------|-----------|-----------|
| 买卖合同 | 购买、出售、货款、验货 | 质量标准、所有权转移、货款结算 |
| 服务合同 | 提供服务、服务费、服务期限 | 验收标准、人员资质、成果归属 |
| 劳动合同 | 劳动者、用人单位、试用期 | 法定必备条款、试用期上限、竞业限制 |
| 保密协议 | 保密信息、保密义务、商业秘密 | 保密范围、接收方身份、泄露救济 |
| 技术合同 | 技术开发、技术转让、专利 | 成果归属、职务发明、出口管制 |
| 建设工程合同 | 工程承包、施工、竣工 | 质保金比例、工程款节点、竣工验收 |
| 涉外合同 | foreign、跨境、境外方 | 激活涉外专项检查 F.1-F.6 |
| 数据/隐私合同 | 个人信息、数据处理、数据安全 | 《个保法》合规、数据跨境、安全评估 |

## 输出文件

| 文件 | 说明 |
|------|------|
| `{合同名称}_审核版.docx` | 带批注的合同文档 |
| `合同概要.docx` | 合同概要文档 |
| `综合审核意见.docx` | 四段式审核意见 |
| `业务流程图.mmd` / `.png` | Mermaid 流程图 + 渲染图片 |
| `审核报告.txt` | 文本格式审核报告 |

## 工作流程

```
1. 自动检测格式 → 2. 读取文本 → 3. 合同类型识别 → 4. 五层审核
→ 5. 审核发现预览 → 6. 添加批注 → 7. 生成概要 → 8. 生成意见
→ 9. 生成流程图 → 10. 重新打包
```

## 依赖

- Python 3.9+

- `defusedxml` — 安全 XML 解析
- `python-docx` — DOCX 文件生成

## 使用方式

使用以下关键词触发技能：

- 中文：合同审查、审核合同、合同审核、审合同、合同检查
- 英文：contract review、review contract、check contract

提供合同文件（.docx 或 .pdf）后，技能将自动执行审核流程。

## 风险等级编码

批注的风险等级通过审阅者名称编码，不在批注正文内显示：

| 等级 | 标记 | 说明 |
|------|------|------|
| 🔴 高风险 | 审阅者名称含标记 | 可能导致合同无效或重大损失 |
| 🟡 中风险 | 审阅者名称含标记 | 存在争议风险但业务仍可进行 |
| 🔵 低风险 | 审阅者名称含标记 | 对业务影响较小 |
