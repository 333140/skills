# 综合审核意见模板（四段式）

基于合同概要和审核发现，为业务团队生成结构化四段式审核意见。输出必须遵循合同语言。请参考 **[language.md](language.md)**。

Default output file name: `综合审核意见.docx` for Chinese or `Consolidated_Opinion.docx` for English.

## 第一段：总体评估（1-2句）

格式："本合同整体[可接受/存在重大风险/建议重新起草]。共发现 🔴 高风险 [N] 项、🟡 中风险 [N] 项、🔵 低风险 [N] 项。"

若 Layer 0 命中，需额外说明："其中合法性前置审查发现 [N] 项潜在效力瑕疵问题。"

## 第二段：重大风险摘要（分点列示，仅列 🔴 项）

格式（每项一行）：
"- [条款定位]：[风险描述] → 建议：[一句话对策]"

**示例：**
- 第5.1条付款条款：总金额与第3.2条不一致（100万 vs 1000万），建议统一并明确含税口径。
- 第12条争议解决：仲裁机构名称（"北京仲裁委员会"）存在歧义，建议改为"中国国际经济贸易仲裁委员会"。

## 第三段：谈判优先级建议（新增）

"在进入合同谈判时，建议优先争取以下修改：
1. [最重要的修改点]（影响：……）
2. [次重要的修改点]（影响：……）
3. [可接受的让步点]（影响：……）"

## 第四段：签署前置条件（新增）

"建议在以下条件满足后方可签署：
□ [必须满足的条件1]
□ [必须满足的条件2]
（如无前置条件，此段可省略）"

---

*本审查报告由 AI 辅助生成，仅供参考，不构成法律意见。*

## 输出要求

- 严格遵循四段式结构
- 编号项目在富文本输出中应为**独立段落**
- 语言简洁、专业、客观
- 不引入审核发现中未提及的新风险
