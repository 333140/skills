# 合同审查检查清单

## Layer 0：合法性前置审查（新增）

> 本层检查条款是否触及法律强制性规定或违反公序良俗，凡命中均为 🔴 高风险。

### 0.1 合同主体资质
- [ ] 合同主体是否具备相应民事行为能力或经营资质（《民法典》第143条）
- [ ] 特殊行业是否具备行政许可或资质证书

### 0.2 意思表示真实性
- [ ] 是否存在欺诈、胁迫、重大误解的明显迹象（《民法典》第147-151条）
- [ ] 是否存在显失公平的条款安排

### 0.3 格式条款合规
- [ ] 是否包含排除对方主要权利的格式条款（《民法典》第497条）
- [ ] 格式条款是否已履行提示和说明义务

### 0.4 违约金对等性
- [ ] 违约金条款是否存在显著不对等（《民法典》第585条）
- [ ] 违约金比例是否畸高（超过实际损失30%可能被调整）

### 0.5 强制性规定合规
- [ ] 是否违反法律、行政法规的强制性规定（《民法典》第153条）
- [ ] 是否涉及法律禁止的交易标的或方式

### 0.6 公序良俗
- [ ] 是否违背公序良俗（《民法典》第153条第2款）
- [ ] 是否存在损害社会公共利益的约定

**风险等级：** 🔴 高（Layer 0 命中均为高风险，必须出具批注）

## 第一层：基础审核（文本质量）

### 1. 文本准确性
- [ ] 关键术语和拼写正确
- [ ] 数字、金额和比例准确
- [ ] 大写金额与数字一致
- [ ] 日期精确（避免模糊术语如"尽快"）

### 2. 格式一致性
- [ ] 标点符号正确
- [ ] 条款编号连续
- [ ] 无重复编号
- [ ] 布局整洁
- [ ] 签名区域有足够空间

### 3. 表达清晰度
- [ ] 无语法错误
- [ ] 无模糊陈述
- [ ] 时间/数量/质量无歧义
- [ ] 术语使用正确

### 4. 内部一致性
- [ ] 同一概念使用一致命名
- [ ] 交叉引用正确
- [ ] 条款间无逻辑冲突
- [ ] 附件与正文匹配

**风险等级指导：**
- 🔴 高：核心术语（价格、标的、权利义务）存在歧义
- 🟡 中：非核心术语存在歧义
- 🔵 低：实际影响最小

## 第二层：商业条款

> **优先级说明：** P0 = 必须出具批注；P1 = 有问题时出具批注；P2 = 建议性提示，可在"跳过低风险"模式下省略

### 1. 目的与期限
- [ ] 目的明确
- [ ] 背景说明
- [ ] 开始/结束日期明确
- [ ] 续约条款明确（如适用）

### 2. 标的物（P0）
- [ ] 数量具体
- [ ] 类别/品牌/型号/规格明确
- [ ] 质量标准明确
- [ ] 验收条款可执行
- [ ] 合法性/所有权状态明确

### 3. 价格与付款（P0）
- [ ] 价格结构清晰
- [ ] 定价方法明确
- [ ] 货币明确
- [ ] 税费分离明确
- [ ] 税费责任明确
- [ ] 付款方式明确
- [ ] 付款里程碑与业绩对齐
- [ ] 付款条件可执行
- [ ] 发票/收据条款明确

### 4. 履行
- [ ] 履行时间表具体
- [ ] 履行地点具体
- [ ] 履行方法详细
- [ ] 履行流程结构化
- [ ] 所有权转移点明确
- [ ] 风险转移点明确
- [ ] 通知义务明确

### 5. 权利与义务（P1）
- [ ] 主要权利完整
- [ ] 无默示放弃
- [ ] 免责条款合理
- [ ] 主要义务完整
- [ ] 义务标准明确
- [ ] 义务可行
- [ ] 合同后义务明确
- [ ] 附属权利/义务明确

### 6. 知识产权（P0 技术类/P1 其他）
- [ ] 现有IP所有权明确
- [ ] 履行期间创造的IP明确
- [ ] IP使用的范围/目的/期限明确
- [ ] IP转让/许可条款明确
- [ ] 保护责任明确
- [ ] 保密/竞争限制合理

**风险等级指导：**
- 🔴 高：核心业务因矛盾/歧义/缺失无法进行
- 🟡 中：存在重大争议风险但业务仍可进行
- 🔵 低：对业务影响最小

## 第三层：法律条款

> **优先级说明：** P0 = 必须出具批注；P1 = 有问题时出具批注；P2 = 建议性提示，可在"跳过低风险"模式下省略

### 1. 效力（P0）
- [ ] 成立与生效区分明确
- [ ] 生效条件明确
- [ ] 条件可行性已考虑
- [ ] 生效前法律责任已处理

### 2. 责任/违约（P0）
- [ ] 违约类型明确
- [ ] 救济措施明确
- [ ] 违约金比例合理
- [ ] 责任平衡
- [ ] 计算方法明确

### 3. 变更/终止（P1）
- [ ] 变更条件明确
- [ ] 变更程序明确
- [ ] 终止条件合理
- [ ] 终止程序可执行
- [ ] 期满条件明确
- [ ] 存续条款合理
- [ ] 终止后义务明确

### 4. 适用法律（P0）
- [ ] 适用法律已指定
- [ ] 法律选择合理
- [ ] 与强制性规定无冲突
- [ ] 可执行性已考虑

### 5. 保密（P1）
- [ ] 保密信息已定义
- [ ] 保密期限明确
- [ ] 例外条款有限且合理
- [ ] 违反责任明确

### 6. 不可抗力（P2）
- [ ] 事件定义合理
- [ ] 通知义务明确
- [ ] 免责条件公平
- [ ] 后续措施明确

### 7. 争议解决（P0）
- [ ] 争议解决方式明确
- [ ] 管辖/仲裁机构明确
- [ ] 仲裁与诉讼无冲突
- [ ] 适用法律与争议解决机构匹配

### 8. 通知（P1）
- [ ] 通知方式明确
- [ ] 地址/联系方式完整
- [ ] 生效时间/条件明确
- [ ] 地址变更通知义务明确

### 9. 授权
- [ ] 授权人员明确
- [ ] 范围/权限明确
- [ ] 期限合理
- [ ] 撤销/变更机制明确

### 10. 其他法律条款（P2）
- [ ] 解释规则明确
- [ ] 签署时间/地点明确
- [ ] 可分割性明确

**风险等级指导：**
- 🔴 高：缺失法律条款或不合理责任
- 🟡 中：其他重大问题
- 🔵 低：次要问题

## 专项检查

### 涉外合同专项（当识别为涉外合同时激活）
- [ ] F.1 法律适用是否明确排除 CISG
- [ ] F.2 争议解决是否选择国际仲裁机构
- [ ] F.3 外汇支付条款是否符合外汇管理局监管要求
- [ ] F.4 是否涉及出口管制商品或技术
- [ ] F.5 香港/澳门法律适用是否明确区分
- [ ] F.6 合同语言版本以哪个为准

### 电子合同专项（当检测为电子格式时激活）
- [ ] E.1 电子签名是否符合可靠电子签名条件
- [ ] E.2 电子签名服务提供商是否为经认证的第三方
- [ ] E.3 合同是否属于不得使用电子签名的类型
- [ ] E.4 电子合同存储与归档方式是否有明确约定

### 合同类型差异化检查（根据识别结果激活）
- 买卖合同：质量标准、所有权转移时点、货款结算方式
- 服务合同：服务验收标准、人员资质、成果归属
- 劳动合同：法定必备条款、试用期上限、竞业限制36个月上限
- 保密协议：保密范围是否过宽致无效、接收方身份、泄露救济措施
- 技术合同：技术成果归属、职务发明判断、技术出口管制
- 建设工程合同：质保金比例（≤5%）、工程款支付节点、竣工验收程序
- 数据/隐私合同：《个保法》合规条款、数据跨境传输、安全评估义务

## 使用说明

### Review Process
1. Review in order: Layer 0 → Layer 1 → Layer 2 → Layer 3 → 专项检查
2. Evaluate each checklist item
3. Record findings and risk levels
4. Add structured comments to the document

### Comment Format
Each comment must include:
- **Issue type** (matches checklist)
- **Risk reason** (impact and reasoning)
- **Revision suggestion** (actionable fix)

Risk level is encoded by reviewer name; **do not** add a "risk level" line inside the comment body.

### Priority
- **P0**: must annotate; always include regardless of review mode
- **P1**: annotate when issue found; include in "skip low risk" mode
- **P2**: suggestion only; can be omitted in "skip low risk" mode
