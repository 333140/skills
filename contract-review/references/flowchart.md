# 业务流程图提取（Mermaid）

从合同中提取完整的商业交易流程，生成Mermaid流程图。

**语言规则：** 使用合同语言作为节点文本和标签。请参考 **[language.md](language.md)**。

## 提取要求

### 1. 流程完整性
- 覆盖从合同签署到履行的完整生命周期
- 包含正常履行、违约处理和终止
- 展示双方之间的互动、权利和义务

### 2. 信息精确性
- **时间点**：提取明确的时间要求和触发条件（例如，X个工作日，X小时）
- **金额**：提取金额和比例（例如，30%预付款，总金额）
- **数量/规格**：提取数量、型号、技术规格
- **地点**：交付/验收地点
- **标准**：验收标准、质量要求、技术规格
- **严格来源**：所有提取数据必须来自合同文本

### 3. 节点格式
- 每个节点使用方括号 `[]`
- 使用 `<br>` 分隔多个项目
- 边缘标签显示触发条件/时间要求：`|条件|`；如果缺失，使用 `?`

### 4. 流程逻辑
- 使用 `-->` 表示正常流程
- 包含决策分支（例如，验收通过/失败）
- 包含并行流程（例如，风险转移 vs. 所有权转移）
- 展示违约结果的升级（轻微 → 严重 → 终止）

### 5. 视觉样式
在末尾添加样式：
- 正常履行节点：`style [nodeId] fill:#e6e6fa`
- 违约相关节点：`style [nodeId] fill:#ffff99`
- 终止节点：`style [nodeId] fill:#ff6666`
- 正常完成节点：`style [nodeId] fill:#90ee90`

## 输出格式
- **仅**输出Mermaid代码，以 `flowchart TD` 开头
- 不添加额外解释或代码框
- 语法必须有效且可渲染
